# StatefulEffects Technical Demo

Пять эффектов в двух рядах, по возрастанию сложности слева направо. Одна камера показывает объекты и их короткие подписи. Слева — управление и состояние группы.

| Эффект | Что показывает |
| --- | --- |
| Animator | Куб меняет масштаб и поворот через готовый AnimatorShowHide. |
| Particle System | Появление через Color over Lifetime, завершение скрытия по событию остановки. |
| uGUI | Вертикальная панель проявляется, кнопка и надпись въезжают навстречу друг другу и растут. |
| LitMotion | Семь звёзд по очереди падают на разную высоту, пружинят, деформируются и слегка покачиваются вокруг Y. При скрытии втягиваются наверх. |
| Coroutine | Меняются эмиссия сферы и интенсивность Point Light. Поверхность показывает действие света, URP Bloom даёт ореол. |

`TechnicalDemo` сам реализует IShowHide и получает пять ссылок MonoShowHide из сцены. In Sequence ждёт каждый эффект по очереди, All Together запускает их в одном кадре и ждёт через UniTask.WhenAll. Режим фиксируется в начале каждой команды.

`TechnicalDemoControls` на объекте Control Panel связывает кнопки с командами, выставляет начальное состояние и отображает состояние группы. Во время перехода выбор режима и Show/Hide отключены. SetShown и SetHidden отменяют ожидание текущего прохода и сразу применяют команду ко всем эффектам.

Сцена, EventSystem, меню и пять экземпляров EffectContainer настроены в редакторе. Каждый контейнер держит отдельный префаб эффекта и подписку на его состояние для TMP-подписи.
